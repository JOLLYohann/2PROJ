# 2PROJ
Projet fin de deuxième année SUPINFO

Github: https://github.com/JOLLYohann/2PROJ/

requirements:
pygame
pyinstaller (optionnal: if you want to build it yourself)

build command: python -m PyInstaller --onedir --windowed --name SupSugar --add-data "assets;assets" --add-data "cache/level_data.json;cache" main.py

you will find the .exe in: 2PROJ\dist\SupSugar\SupSugar.exe
